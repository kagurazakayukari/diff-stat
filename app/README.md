# 改动审阅 0.33.0

Hana v2 App。只展示当前主对话最近采集到的文件 diff，支持实时更新、文件展开收起和主题切换。

## 使用

安装并允许权限后，从卡片中心打开“改动审阅”。每次用户输入登记新一轮，成功执行 edit / write 后立即更新面板。没有新文件改动时保留最近一次差异。

- 只显示最新差异，没有历史批次选择、回撤、文件恢复或确认弹窗。
- 刷新当前对话通过宿主标题栏动作触发，正文不再放置刷新按钮。
- 状态行仅显示最后成功采集时间，精确到秒，替代采集中提示；刷新和轮末状态更新不改变时间。不重复展示时间，没有时间数据的旧记录不显示伪造时间。错误时显示具体原因。
- 文件名使用相对路径，显示新增与删除数量、旧新行号、hunk 和逐行红绿背景。
- Hana 风格控件，初始加载和主题切换均使用宿主提供的真实主题 CSS。
- App 设置提供路径基准目录和默认是否展开详情。默认详情偏好在下一次差异发布时更新到记录；面板不额外发起设置 HTTP 请求。
- 0.32 移除会受页面 HTTP 许可过期影响的 /preferences 请求与路由。读取已授权的 App 存储后直接展示最新投影，不续签或复用过期许可；宿主桥接本身失效时仍需由宿主重新打开页面。
- 只查询轻量主会话目录，不读取完整会话历史或整棵树。
- 同一轮多次编辑合并展示；改前文本仅在内存中用于差异计算，不新增磁盘字节快照。
- 每个主对话只更新 current 展示记录，不新增 prev、history 或 batch 存储。早期版本的历史数据保留原位，不再读取、更新或提供浏览入口。
- 不生成对话卡，不保存或发送对话审阅正文。

## 权限

- app/hooks.session-input：登记当前用户输入对应的差异范围，不修改输入。
- app/hooks.tools-pre-execute / post-execute：读取改前文本并采集工具结果。
- app/sessions.read：主对话定位和前台会话切换。
- app/resources.read：通过 ResourceIO 读取差异文本。

已移除 app/resources.write、app/sessions.manage 和 app/hooks.observe。应用不提供文件写入、消息投递或广泛生命周期观察；0.33 不再监听轮末事件。保留的五项权限均有直接功能用途。

## 限制与验证

只采集主对话的 edit / write，不采集 Shell、外部编辑器或子代理改动。升级时已经运行的回合需要下一次用户输入后才能登记；运行中重载不会保存内存里的差异基线。每文件预览最多 400 行，非 UTF-8 文本预览可能不准确。旧版数据不会自动清理。

成功工具改动立即发布，不依赖结束事件。每次新用户输入替换内存中的本轮基线。会话切换订阅失败时可使用标题栏刷新。

独立检查覆盖同轮合并、新轮替换、实时预览、会话隔离、失败工具不更新、只保存最新投影、无恢复路由与旧数据不变；DOM 检查覆盖最新差异展示、主题样式加载、展开收起以及无历史和回撤控件。以上为源码验证，不等于安装后的生命周期验收。官方独立 smoke 曾受运行时和隔离钩子组合限制，未记为通过。
