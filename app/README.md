# 改动审阅 0.25.0

Hana v2 App。应用面板按对话查看 `edit` / `write` 的历史 diff，提供单文件回滚和撤销最近一轮。不生成、保存或发送对话审阅正文。

## 使用

- 应用设置提供路径基准目录和应用面板默认详细程度。
- 使用 Hana Card Style 主题与控件，无重复标题区。0.24 显式加载初始宿主主题样式，并在切换时替换配色，防止较慢的旧请求覆盖新主题；主题加载失败显示原因。窄面板保留旧新行号和红绿增删色。
- 所有显示偏好只在 App 设置里修改。应用面板提供批次选择（默认最新批次）、文件展开收起与回滚。
- 已移除对话正文生成及对话 iframe 映射，不再向对话投递审阅内容。
- 应用启动时清除私有历史批次中的 conversationContent 字段，保留 diff 与回滚快照。
- 0.25 在 agent/before-start 建立并持久化本轮批次标识，文件编辑时不再读取会话历史或整棵树，避免长会话超过 App RPC 的 32 MiB 上限。重载后可继续当前已登记批次。
- 主对话身份通过宿主的会话引用解析，不再枚举列表匹配路径。子代理会话明确跳过，不混入主对话。
- 升级或授权时已经开始、且尚未登记的回合不补造批次，从下一次完整回合开始采集。应用面板动态查询历史。
- 宿主切换监听失败时可使用“刷新当前对话”，不清空已经显示的记录。
- 文件改动继续采集。已经发送到聊天里的消息不由本应用修改或删除。

## 回滚

从 0.15.0 安装并获授权后的改动开始保存原始字节快照。一个文件本轮多次修改，保留最初内容与最后结果。
在最近一轮点击“回滚此文件”或“撤销本轮”，先检查所有目标文件，列出恢复清单，用户确认后再次校验。
使用 ResourceIO 的版本条件写入；后来发生的文件编辑会导致拒绝覆盖。

- 只恢复已有文件，不自动删除新建文件；新文件和缺少快照的旧记录明确禁用回滚。
- 只恢复最近一轮；上一轮页签只用于查看。
- 整轮恢复先预检所有可恢复的已有文件，再逐文件条件写入；新建文件及不可校验文件明确列为保留项。跨多个文件不具备事务原子性，中途失败会报告已恢复和未恢复的文件。
- 预览每文件最多 400 行，原始快照不截断。快照保存于 App 私有数据目录，不包含在 UI 展示存储里。
- 非 UTF-8 文件的差异预览可能不准确；回滚使用保存的原始字节。

## 权限

会话钩子采集修改，会话读取用于解析稳定主对话身份。0.25 新增 `app/hooks.agent-before-start` 用于登记回合，必须在安装审核中允许；不修改模型提示词。`app/sessions.manage` 沿用旧版声明，当前不调用消息投递。
新增 `app/resources.read` 用于改前/改后快照与冲突检查，`app/resources.write` 用于用户确认后的恢复。
所有项目文件访问经宿主 ResourceIO，未经授权不访问，不使用裸文件接口绕过宿主。

## 验证

临时文件验证：多次编辑、重载持久化、BOM/CRLF 原字节恢复、确认后冲突拒绝、跨文件部分恢复报告、A/B 对话隔离、新建文件禁用、关闭对话卡继续采集。
独立 DOM 验证：旧流内页面不查询或猜测批次，应用面板切换对话、历史选择和展开收起。后端验证：不生成或投递对话正文，回滚与冲突处理正常。长会话回归检查禁止调用 entries/history/list，仍可完成采集、同轮合并及重载恢复；子代理跳过不写其他会话。以上为源码验证。
官方静态校验通过。官方独立 smoke 组合缺少 `sessionHooks` 服务，无法验证会话钩子真实生命周期；安装后仍需真机核对。
